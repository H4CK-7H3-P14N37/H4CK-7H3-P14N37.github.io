Curse Catcher — Critical CVEs

RBH Access Technologies (Integra32 access control)

  • ■ CVE-2026-63079: Integra32 remote code execution as SYSTEM without login (CVSS 9.8) — Integra32 Security Management System 5.1.11 R5.0 runs an old .NET Remoting service on TCP port 2001 that accepts malicious data from anyone and runs it as SYSTEM, which also allows file read/write and credential theft. This is a building access-control server, so block port 2001 from untrusted networks now. No known exploitation and not in KEV. A researcher's write-up is linked. NVD returned HTTP 503 for this CVE. Source NVD VulnCheck advisory Researcher write-up.

VITEC (EZ TV Platform)

  • ■ CVE-2026-82504: EZ TV Platform Server unauthenticated web shell upload (CVSS 9.8) — Before 8.5.0, anyone can upload an ASPX file through the upload handler by naming it in a request header, and the file runs right away on the web server. Patches exist for 8.3.0 through 8.4.1; older releases need 8.5.0 or later. No known exploitation and not in KEV. NVD returned HTTP 503 for this CVE. Source NVD VulnCheck advisory.

sysPass (password manager)

  • ■ CVE-2026-129110: sysPass can be reinstalled by anyone, leading to code execution (CVSS 9.8) — In 3.0.1 through 3.2.11, the installer never checks whether sysPass is already installed. An attacker can re-run it, point the app at their own database, create an admin account and then run commands. This is a self-hosted password vault, so a takeover exposes every stored credential. Keep it off the internet or block the install path until a fix ships. No known exploitation and not in KEV. NVD returned HTTP 503 for this CVE. Source NVD VulnCheck advisory GitHub issue.

PLANET Technology (managed switches)

  • ■ CVE-2026-109445: GS-5220-8P2T2S switch stack overflow via login cookie (CVSS 9.8) — On hardware version 3.0 with firmware before 3.2412b261008, an oversized login cookie in an unauthenticated web request overflows a stack buffer and can crash the switch or corrupt memory. Update the firmware and keep the management web interface off untrusted networks. No known exploitation and not in KEV; NVD has not analyzed it yet. Source NVD PLANET advisory VulnCheck advisory.

NginxPulse (open-source Nginx log analytics)

  • ■ CVE-2026-129171: NginxPulse unauthenticated SQL injection with file read/write (CVSS 9.8) — In 1.5.0 up to 1.6.26, two parameters of the stats API let anyone inject SQL. That gives them the database contents and, with PostgreSQL superuser rights, the ability to read and write server files. Upgrade to 1.6.26. No known exploitation and not in KEV. NVD returned HTTP 503 for this CVE. Source NVD VulnCheck advisory Fix commit.

Jet Admin (cloud platform)

  • ■ CVE-2026-123965: Jet Admin prompt injection leaks platform secrets (CVSS 9.9) — Anyone with a free account could use prompt injection to read the platform's configuration files and steal credentials. The vendor says it fixed this on its side around Oct 29, so customers have nothing to patch, but they should consider rotating any credentials they stored there. No known exploitation, cannot easily be scripted at scale, full impact if exploited. Not in KEV. CISA published an advisory. NVD returned HTTP 503 for this CVE. Source NVD CISA advisory (CSAF) Jet Admin changelog.

Elextensions (ELEX HelpDesk for WordPress)

  • ■ CVE-2026-125855: ELEX HelpDesk PHP object injection (CVSS 9.8) — Versions up to 3.3.9 load untrusted data in a way that allows object injection. No known exploitation, but the attack can be scripted at scale and gives full control. This is a second critical bug in the same plugin version as yesterday's code-execution flaw, so update or remove the plugin. Not in KEV. Source NVD Patchstack.

AutomatorWP (WordPress)

  • ■ CVE-2026-126173: AutomatorWP Pro webhook lets anyone reset any password (CVSS 9.8) — Up to 1.4.4, an unauthenticated attacker can reset any account's password, admins included, but only when the site has a specific webhook-to-update-user automation with the user ID left blank (a documented setup). Check your automations and update. No known exploitation and not in KEV. NVD returned HTTP 503 for this CVE. Source NVD Wordfence.

themagnifico52 (Hotel Booking Lite WordPress theme)

  • ■ CVE-2026-125851: Hotel Booking Lite theme web shell upload (CVSS 9.9) — Versions up to 2.5.1 allow dangerous file uploads that can plant a web shell. No known exploitation and cannot easily be scripted at scale, but full site control if exploited. Not in KEV. Update or switch themes. Source NVD Patchstack.
