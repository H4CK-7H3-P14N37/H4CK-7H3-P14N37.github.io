## Curse Catcher — Critical CVEs

### HPE Aruba Networking (AirWave)

- **[CVE-2026-133973: unauthenticated command injection in AirWave web management (CVSS 9.8)](https://nvd.nist.gov/vuln/detail/CVE-2026-133973)** _(HPE, Nov 25)_ — An unauthenticated remote attacker can run operating-system commands on the AirWave server. No known exploitation yet and not in KEV; no CISA rating yet. AirWave manages fleets of wireless gear, so keep its web interface off the internet and patch per HPE bulletin HPESBNW05186.  
  [NVD](https://nvd.nist.gov/vuln/detail/CVE-2026-133973) · [HPE advisory](https://support.hpe.com/hpesc/public/docDisplay?docId=hpesbnw05186en_us&docLocale=en_US)

No known exploitation, not in KEV. Combined with the command injection above, this is a full-takeover path; same HPE fix.  
  [NVD](https://nvd.nist.gov/vuln/detail/CVE-2026-133971) · [HPE CSAF](https://csaf.arubanetworking.hpe.com/2026/hpe_networking_-_hpesbnw05186.txt)
