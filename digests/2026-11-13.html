Curse Catcher — Critical CVEs

Citrix NetScaler

  • ■ CVE-2026-107412: NetScaler ADC and Gateway memory overflows (CVSS 9.5) — Several memory overflow bugs in NetScaler ADC and NetScaler Gateway can cause erratic behavior and denial of service. It is part of a 12-flaw Citrix patch release that also fixes an authentication bypass. No known exploitation, but NetScaler gateways have been mass-exploited repeatedly (CitrixBleed), so patch internet-facing appliances first. Source NVD Citrix advisory The Hacker News.

Copeland (Dixell) XWEB EVO

  • ■ CVE-2026-124002: XWEB EVO pre-login command injection as root (CVSS 9.8) — Unauthenticated attackers can inject shell commands through the username field of the login and API pages (versions 5.2.3 up to 5.7.0) and get root through a setuid interpreter. XWEB EVO is a refrigeration and HVAC monitoring controller that reached end of service in March 2026, so replace it or keep it off the internet. Source NVD VulnCheck advisory.
  • ■ CVE-2026-124004: XWEB EVO hardcoded administrator password (CVSS 9.8) — Versions before 5.6.2 have a built-in backdoor password that gives anyone full admin access in a single request. The password is now public, so any exposed unit should be treated as open. No known exploitation. Source NVD VulnCheck advisory End-of-service bulletin.
  • ■ CVE-2026-124010: XWEB EVO console CGI command injection as root (CVSS 9.8) — Before 5.6.2, unauthenticated attackers can pass commands to a setuid-root console script and take over the device. The NVD lookup for this CVE timed out, so details come from the VulnCheck and Copeland advisories. No known exploitation. Source NVD VulnCheck advisory.

Linksys EA8100 router

  • ■ CVE-2026-127275: EA8100 remote-management settings writable without login (CVSS 10.0) — On firmware 1.0.3.216940, the router's management API lets anyone change remote-management pairing and the unsecured Wi-Fi warning without authenticating. The researcher's write-up is public and Linksys did not respond to the report, so no fix is known. Home users should disable remote management. Source NVD Researcher write-up VulDB.
  • ■ CVE-2026-127277: EA8100 anonymous file sharing maps to the admin account (CVSS 10.0) — When anonymous access to the router's SMB file sharing is turned on, guests get admin rights on the share. The details are public and there is no vendor fix, so turn off anonymous file sharing. Source NVD Researcher write-up.

Red Hat (rubygem-safemode, used by Foreman / Satellite)

  • ■ CVE-2026-107360: safemode template sandbox escape (CVSS 9.6) — A logged-in user who can edit templates can call methods the sandbox should block, including destructive ones such as deleting hosts. Red Hat has shipped fixes; restrict who can edit provisioning templates. No known exploitation. Source NVD Red Hat.

Joomla jDownloads extension

  • ■ CVE-2026-117551: jDownloads thumbnail upload leads to PHP code execution (CVSS 10.0) — Before 4.1.8, users with upload permission can place executable files on the server. No known exploitation, but the attack can be scripted at scale and gives full control of the site. Update and review who has upload rights. Source NVD jDownloads.

WordPress plugins

  • ■ CVE-2026-119077: ELEX HelpDesk unauthenticated code execution (CVSS 9.8) — Up to 3.3.9, an anonymous visitor can grab a token from any public support page and then run code with one request. No known exploitation, but two-request bugs like this usually get mass-scanned quickly. Source NVD Wordfence.
  • ■ CVE-2026-125055: Chatterbug Forms unauthenticated PHP upload (CVSS 9.8) — Up to 1.0.2, anyone can upload a PHP file through a public form and run code. No known exploitation; update or remove the plugin. Source NVD Wordfence.

OpsTree BuildPiper

  • ■ CVE-2026-127073: BuildPiper project users can become Kubernetes cluster-admin (CVSS 9.9) — Before 2.7.0, the Additional Manifest feature applies any manifest with cluster-wide credentials, so a project user can grant themselves cluster-admin and reach every workload and secret. A public researcher write-up describes it. No known exploitation. Source NVD VulnCheck advisory Researcher write-up.
  • ■ CVE-2026-127080: BuildPiper container escape through host-path volumes (CVSS 9.9) — Before 2.7.0, deploy users can mount the worker node's whole filesystem read-write and break out of the container. Same researcher as yesterday's OpsTree REMS bug; upgrade to 2.7.0. Source NVD VulnCheck advisory.

FrankenPHP

  • ■ CVE-2026-128027: FrankenPHP Docker images shipped stale, vulnerable libraries (CVSS 9.8) — Before 1.1.11, images were only rebuilt for new tags, so Alpine, PHP and Go security fixes (for example a libcrypto code-execution bug) never reached existing tags. Pull fresh images and redeploy. Source NVD GitHub advisory.

Frappe HRMS

  • ■ CVE-2026-126315: Frappe HRMS sends HR data as telemetry even when disabled (CVSS 9.8) — Versions 16.14.0 up to 16.20.1 send usage events with leave types, claim amounts and appraisal scores even when telemetry is off. It is a privacy leak, not a takeover, despite the score. Upgrade to 16.20.1. Source NVD GitHub advisory.
