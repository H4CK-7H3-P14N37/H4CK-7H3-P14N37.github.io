## Curse Catcher — Critical CVEs

### Citrix NetScaler

- **[CVE-2026-107412: NetScaler ADC and Gateway memory overflows (CVSS 9.5)](https://nvd.nist.gov/vuln/detail/CVE-2026-107412)** — Several memory overflow bugs in NetScaler ADC and NetScaler Gateway can cause erratic behavior and denial of service. It is part of a 12-flaw Citrix patch release that also fixes an authentication bypass. No known exploitation, but NetScaler gateways have been mass-exploited repeatedly (CitrixBleed), so patch internet-facing appliances first.  
  [NVD](https://nvd.nist.gov/vuln/detail/CVE-2026-107412) · [Citrix advisory](https://support.citrix.com/support-home/kbsearch/article?articleNumber=CTX697305) · [The Hacker News](https://thehackernews.com/2026/11/citrix-patches-12-netscaler-and-secure.html)

### Copeland (Dixell) XWEB EVO

- **[CVE-2026-124002: XWEB EVO pre-login command injection as root (CVSS 9.8)](https://nvd.nist.gov/vuln/detail/CVE-2026-124002)** — Unauthenticated attackers can inject shell commands through the username field of the login and API pages (versions 5.2.3 up to 5.7.0) and get root through a setuid interpreter. XWEB EVO is a refrigeration and HVAC monitoring controller that reached end of service in March 2026, so replace it or keep it off the internet.  
  [NVD](https://nvd.nist.gov/vuln/detail/CVE-2026-124002) · [VulnCheck advisory](https://www.vulncheck.com/advisories/dixell-copeland-xweb-evo-pre-authentication-os-command-injection-via-username)
- **[CVE-2026-124004: XWEB EVO hardcoded administrator password (CVSS 9.8)](https://nvd.nist.gov/vuln/detail/CVE-2026-124004)** — Versions before 5.6.2 have a built-in backdoor password that gives anyone full admin access in a single request. The password is now public, so any exposed unit should be treated as open. No known exploitation.  
  [NVD](https://nvd.nist.gov/vuln/detail/CVE-2026-124004) · [VulnCheck advisory](https://www.vulncheck.com/advisories/dixell-copeland-xweb-evo-hardcoded-administrator-backdoor-password) · [End-of-service bulletin](https://webapps.copeland.com/dixell/Content/Pages/AdvertisingMaterials/ProductNews/XWEB%20EVO%20EoS%20-%20Product_Bulletin_March_2026.pdf)
- **[CVE-2026-124010: XWEB EVO console CGI command injection as root (CVSS 9.8)](https://nvd.nist.gov/vuln/detail/CVE-2026-124010)** — Before 5.6.2, unauthenticated attackers can pass commands to a setuid-root console script and take over the device. The NVD lookup for this CVE timed out, so details come from the VulnCheck and Copeland advisories. No known exploitation.  
  [NVD](https://nvd.nist.gov/vuln/detail/CVE-2026-124010) · [VulnCheck advisory](https://www.vulncheck.com/advisories/dixell-copeland-xweb-evo-unauthenticated-command-injection-via-xwconsole-cgi)

### Linksys EA8100 router

- **[CVE-2026-127275: EA8100 remote-management settings writable without login (CVSS 10.0)](https://nvd.nist.gov/vuln/detail/CVE-2026-127275)** — On firmware 1.0.3.216940, the router's management API lets anyone change remote-management pairing and the unsecured Wi-Fi warning without authenticating. The researcher's write-up is public and Linksys did not respond to the report, so no fix is known. Home users should disable remote management.  
  [NVD](https://nvd.nist.gov/vuln/detail/CVE-2026-127275) · [Researcher write-up](https://github.com/geo-chen/oss/blob/main/Linksys.md#finding-3-unauthenticated-write-access-to-remote-management-pairing-state-and-unsecured-wifi-warning-flag) · [VulDB](https://vuldb.com/vuln/436430)
- **[CVE-2026-127277: EA8100 anonymous file sharing maps to the admin account (CVSS 10.0)](https://nvd.nist.gov/vuln/detail/CVE-2026-127277)** — When anonymous access to the router's SMB file sharing is turned on, guests get admin rights on the share. The details are public and there is no vendor fix, so turn off anonymous file sharing.  
  [NVD](https://nvd.nist.gov/vuln/detail/CVE-2026-127277) · [Researcher write-up](https://github.com/geo-chen/oss/blob/main/Linksys.md#finding-5-smb-anonymous-access-mapped-to-the-admin-account-when-anonymous-access-is-enabled)
