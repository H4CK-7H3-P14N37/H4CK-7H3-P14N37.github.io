## Curse Catcher — Critical CVEs

### TRENDnet routers

- **[CVE-2026-138004: command injection in UPnP control endpoint on TEW-751DR and TEW-733GR (CVSS 10.0)](https://nvd.nist.gov/vuln/detail/CVE-2026-138004)** — A remote attacker can inject operating-system commands through the soap.cgi UPnP endpoint on firmware 1.03B01. VulDB says exploit details are public (linked write-up), but there's no known exploitation and it's not in KEV. These are older home and small-office routers: turn off UPnP, never expose it to the WAN, and replace the device if TRENDnet doesn't ship a fix.  
  [VulDB](https://vuldb.com/vuln/444939) · [Public write-up](https://gist.github.com/qwq-nm/251e7963d59f41beea2c7ad5ff7ca39f)

Exploit details are public per VulDB; no known exploitation and not in KEV. Same advice: disable UPnP or retire the router.  
  [VulDB](https://vuldb.com/vuln/444940) · [Public write-up](https://gist.github.com/qwq-nm/70b4fd27c21fd32e68f929261c01757f)

### ToolJet

- **[CVE-2026-137964: command injection in ToolJet's GitHub Actions release workflow (CVSS 9.8)](https://nvd.nist.gov/vuln/detail/CVE-2026-137964)** — The release workflow pastes a pull request's title straight into a shell step, so a crafted PR title, once merged, runs commands with a token that can merge into enterprise repositories. A software supply-chain risk for ToolJet itself rather than for deployed servers. Fixed in 3.21.96-LTS. No known exploitation, not in KEV. A good reminder to audit your own workflows for untrusted PR text in run steps.  
  [GitHub advisory](https://github.com/ToolJet/ToolJet/security/advisories/GHSA-74h3-686h-cmvf) · [VulnCheck](https://www.vulncheck.com/advisories/tooljet-before-3.21.96-lts-command-injection-via-release-workflow-pull-request-title)
