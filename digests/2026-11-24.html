Curse Catcher — Critical CVEs

WP connect (WordPress plugins)

  • ■ CVE-2026-135202: backdoor shipped inside six WP connect WordPress plugins (CVSS 9.8) — Releases of Orders Sync to Airtable for WooCommerce, Add-On for Contact Form 7 to Notion, WP Sync for Notion, Add-On for Contact Form 7 to Airtable, Add-on Brevo for Gravity Forms and Air WP Sync contain a module that phones home to tascredit-pay.com every half hour and runs whatever PHP the server sends back: shell commands, file read/write, user-table and password-hash dumps, webshell drops and persistence. This is a supply-chain compromise, not a coding bug. No CISA rating yet, not in KEV. All six plugins are closed on WordPress.org with no fixed version: uninstall them, run a full malware scan, block tascredit-pay.com, and rotate WordPress admin passwords and database credentials. Source Wordfence.

Vates (Xen Orchestra)

  • ■ CVE-2026-133469: authentication bypass in the Xen Orchestra REST API (CVSS 9.8) — A crafted authenticationToken cookie becomes an empty object that matches the first stored token, so an attacker logs in as that token's owner and can then pull reusable login tokens. Fixed in 6.9.2 and 6.10.1. The CVE description says it is actively exploited in the wild; CISA's rating lists a public proof-of-concept, says the attack can be scripted at scale, and says it gives full control. Not in KEV yet. Xen Orchestra manages whole XCP-ng/XenServer estates and their backups, so patch now and keep the web UI off the internet. Source Vates advisory GitHub advisory.
