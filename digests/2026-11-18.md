## Curse Catcher — Critical CVEs

### Apache Roller

- **[CVE-2026-129448: unauthenticated remote code execution via XML-RPC deserialization (CVSS 9.8)](https://nvd.nist.gov/vuln/detail/CVE-2026-129448)** _(Curse Catcher, Nov 18)_ — Roller 4.0.0 through 6.1.4 deserializes XML-RPC requests before checking login, so anyone can run code on the blog server. It is the same bug as CVE-2026-82384, which first listed only 6.1.5 as affected. Apache's advisory says it is being actively exploited, and BleepingComputer reports attacks. It is not in KEV yet, and CISA's rating, which may not be updated yet, still says no known exploitation. Upgrade to 6.1.6. If you can't, set enabledForExtensions to false in web.xml or remove the /roller-services/xmlrpc mapping. Turning off XML-RPC in the admin UI doesn't protect you.  
  [Apache advisory](https://lists.apache.org/thread/cc0jck13nb9vvcmzxzwotr6n16mx28z9) · [Fix PR](https://github.com/apache/roller/pull/171) · [BleepingComputer](https://www.bleepingcomputer.com/news/security/apache-warns-of-roller-rce-vulnerability-exploited-in-attacks/)
