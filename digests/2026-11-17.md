## Curse Catcher — Critical CVEs

### Dassault Systèmes 3DEXPERIENCE (Station Launcher App)

- **[CVE-2026-93664: unauthenticated remote code execution via deserialization (CVSS 10.0)](https://nvd.nist.gov/vuln/detail/CVE-2026-93664)** _(Curse Catcher, Nov 17)_ — Affects 3DEXPERIENCE R2023x through R2026x. Untrusted data is deserialized, letting an attacker run code without logging in. CISA rates it as scriptable at scale with full control of the system, but there is no known exploitation and it is not in KEV. Apply the vendor fix and keep the platform off the internet.  
  [3DS advisory](https://www.3ds.com/trust-center/security/security-advisories/cve-2026-93664)
- **[CVE-2026-19732 and CVE-2026-77033: OS command injection (CVSS 9.9)](https://nvd.nist.gov/vuln/detail/CVE-2026-19732)** _(Curse Catcher, Nov 17)_ — Two separate command-injection bugs in the same component (R2023x through R2026x) let an attacker run commands on the server. The 9.9 score suggests a low-privilege account is needed. CISA rates them as not easily scriptable but with full control if exploited. There is no known exploitation and neither is in KEV.  
  [NVD CVE-2026-77033](https://nvd.nist.gov/vuln/detail/CVE-2026-77033) · [3DS advisory 19732](https://www.3ds.com/trust-center/security/security-advisories/cve-2026-19732) · [3DS advisory 77033](https://www.3ds.com/trust-center/security/security-advisories/cve-2026-77033)

### Arize Phoenix (AI observability platform)

- **[CVE-2026-53998: template injection exposes secrets and enables admin token forgery (CVSS 10.0)](https://nvd.nist.gov/vuln/detail/CVE-2026-53998)** _(Curse Catcher, Nov 17)_ — Versions 13.0.0 to before 15.7.0 let a crafted chat template in a GraphQL query walk Python internals and read environment variables. The endpoint needs no login on default installs. Leaking the Phoenix secret lets an attacker forge admin sessions and decrypt stored credentials. CISA has not rated it yet, there is no known exploitation, and it is not in KEV. Upgrade to 15.7.0 and rotate the secret and any stored provider keys.  
  [GitHub advisory](https://github.com/Arize-ai/phoenix/security/advisories/GHSA-gfv3-m769-5xm3) · [Fix release 15.7.0](https://github.com/Arize-ai/phoenix/releases/tag/arize-phoenix-v15.7.0)

### Zyxel (DSL/Ethernet CPE)

- **[CVE-2026-79614: DX3301-T0 / EX3301-T0 out-of-bounds write (CVSS 9.8)](https://nvd.nist.gov/vuln/detail/CVE-2026-79614)** _(Curse Catcher, Nov 17)_ — Firmware through 5.50(ABVY.8.3)C0 has a memory-corruption bug in a web library that lets an attacker run commands with a crafted HTTP request and no login. WAN access is off by default, so the main risk is from the LAN or units where remote management was turned on. CISA has not rated it yet, there is no known exploitation, and it is not in KEV. Zyxel home and ISP routers are frequent botnet targets, so patch and keep remote management off.  
  [Zyxel advisory](https://www.zyxel.com/global/en/support/security-advisories/zyxel-security-advisory-for-out-of-bounds-write-and-post-authentication-command-injection-vulnerabilities-in-certain-dsl-ethernet-cpe-fiber-onts-and-wireless-extenders-11-17-2026)

### CIRCUTOR PowerStudio SCADA

- **[CVE-2026-120387: JWT 'none' algorithm authentication bypass (CVSS 10.0)](https://nvd.nist.gov/vuln/detail/CVE-2026-120387)** _(Curse Catcher, Nov 17)_ — The desktop version of PowerStudio SCADA accepts unsigned login tokens, so an attacker can impersonate any user without a password. A researcher write-up is linked from the CVE. CISA has not rated it yet, there is no known exploitation, and it is not in KEV. This is energy-monitoring software for industrial sites, so keep it off the internet and limit it to the OT network.  
  [Researcher write-up](https://0day-rubbish.com/blog/circutor-powerstudio-jwt-alg-none-identity-forgery) · [CIRCUTOR security page](https://circutor.com/soporte/ciberseguridad/)

### NodePress (Node.js CMS)

- **[CVE-2026-129952: admin access by forging tokens with the built-in fallback secret (CVSS 9.8)](https://nvd.nist.gov/vuln/detail/CVE-2026-129952)** _(Curse Catcher, Nov 17)_ — Through 8.5.1, if no signing secret is configured, the app falls back to a hardcoded one, so anyone can sign admin tokens. NVD has deferred analysis and CISA has not rated it. There is no known exploitation and it is not in KEV. Set a unique secret.  
  [VulnCheck advisory](https://www.vulncheck.com/advisories/nodepress-through-8.5.1-authentication-bypass-via-default-jwt-signing-secret)
- **[CVE-2026-129955: default admin password 'root' (CVSS 9.8)](https://nvd.nist.gov/vuln/detail/CVE-2026-129955)** _(Curse Catcher, Nov 17)_ — Through 8.5.1, if the admin password setting is left unset, the admin login accepts 'root' and gives full control of the site. NVD has deferred analysis and CISA has not rated it. There is no known exploitation and it is not in KEV. Set a strong admin password.  
  [VulnCheck advisory](https://www.vulncheck.com/advisories/nodepress-through-8.5.1-authentication-bypass-via-default-administrator-password)

### Tensei (Node.js CMS)

- **[CVE-2026-129552: hardcoded JWT key lets anyone impersonate admins (CVSS 9.8)](https://nvd.nist.gov/vuln/detail/CVE-2026-129552)** _(Curse Catcher, Nov 17)_ — Through 0.11.5, @tensei/auth falls back to a hardcoded signing key when no secret is set, so unauthenticated attackers can sign tokens for any user. CISA rates it as scriptable at scale with full control, but there is no known exploitation and it is not in KEV. Set a secret; the project appears unmaintained.  
  [VulnCheck advisory](https://www.vulncheck.com/advisories/tensei-through-0.11.5-authentication-bypass-via-hard-coded-jwt-secret-in-tensei-auth)

### Prime CMS

- **[CVE-2026-129941: anyone can register and get full admin rights (CVSS 9.8)](https://nvd.nist.gov/vuln/detail/CVE-2026-129941)** _(Curse Catcher, Nov 17)_ — Through 0.4.0-beta.0, the login check is commented out and every role is hardcoded to admin, so unauthenticated users can create accounts through GraphQL and take over content, users and webhooks. CISA rates it as scriptable at scale with full control, but there is no known exploitation and it is not in KEV.  
  [VulnCheck advisory](https://www.vulncheck.com/advisories/prime-cms-through-0.4.0-beta.0-authentication-bypass-via-createuser-graphql-mutation)

### TridotsTech go1cms

- **[CVE-2026-130071: unauthenticated document modification (CVSS 9.8)](https://nvd.nist.gov/vuln/detail/CVE-2026-130071)** _(Curse Catcher, Nov 17)_ — A guest-accessible update method saves arbitrary fields while skipping permission checks, letting attackers edit user records to escalate privileges or take over accounts. The fix is in commit ead8da3 on the version-3 branch. CISA has not rated it yet, there is no known exploitation, and it is not in KEV.  
  [VulnCheck advisory](https://www.vulncheck.com/advisories/tridotstech-go1cms-unauthenticated-arbitrary-document-modification-via-update-doc) · [Fix commit](https://github.com/TridotsTech/go1cms/commit/ead8da36a9452b961cc5361d6fd853ca68a58b08)
