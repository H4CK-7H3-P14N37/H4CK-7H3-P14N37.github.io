Curse Catcher — Critical CVEs

F5 BIG-IP

  • ■ CVE-2026-116953, CVE-2026-120285, CVE-2026-120292, CVE-2026-120722, CVE-2026-121805, CVE-2026-123637: traffic engine crash, possible code execution without login (CVSS 9.8) — Each flaw needs a specific virtual-server setup: an iRule using GENERICMESSAGE::route, PSC::ip_address (with an HTTP profile), MR::message route (with an HTTP profile), DNS::scrape or PEM::subscriber, or an APM per-request policy with the Client Information and Endpoint Security agents. A crafted request crashes the traffic engine (TMM) and may allow code execution. Only data-plane traffic is affected, not the management interface. CISA rates them as scriptable at scale with full control. There is no known exploitation and none are in KEV. BIG-IP is a frequent mass-exploitation target, so check your iRules for these commands and patch. Source NVD 120285 NVD 120292 NVD 120722 NVD 121805 NVD 123637 F5 K000163941 F5 K000163937 (APM) The Hacker News.
