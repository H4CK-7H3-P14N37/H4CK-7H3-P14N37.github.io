Curse Catcher — Critical CVEs

Synology

  • ■ CVE-2026-120382: DiskStation Manager OAuth API flaw lets remote attackers read and write files (CVSS 9.8) — An argument-injection bug in the DSM OAuth API lets a remote attacker read or write arbitrary files and crash the NAS. Fixed in DSM 7.1.1-42962-10, 7.2.1-69057-14, 7.2.2-72806-11, 7.3.2-86009-6 and 7.4.1-90080-2. No CISA rating yet, no known exploitation, not in KEV. Internet-facing NAS boxes are a favorite ransomware target: update DSM and keep the management interface off the internet (use VPN or QuickConnect restrictions). Source Synology advisory SA-26:21.

Cribl (data pipeline / log routing)

  • ■ CVE-2026-115873: read-only user can run code on the Leader through a crafted expression (CVSS 9.9) — An attacker with only read-only access to one Worker Group who can reach the Leader API can use a crafted expression to escape the expression sandbox and run code as the Leader service account. The CVE text doesn't name the product; Cribl's advisory has the affected versions. No CISA rating yet, no known exploitation, not in KEV. The Leader controls every worker and holds pipeline credentials, so patch it and restrict who can reach the Leader API. Source Cribl advisory 2026-0006 Cribl notifications.
  • ■ CVE-2026-115899: malicious pagination data from an upstream API runs code on Workers (CVSS 9.8) — If an attacker controls the pagination data an upstream service returns to an existing REST Collector that uses response-based pagination, the next job run executes their code as the Worker service account. Harder to reach, since the attacker needs to control or compromise the upstream API. No CISA rating yet, no known exploitation, not in KEV. Patch, and review REST Collectors pointed at third-party APIs. Source Cribl advisory 2026-0007.

TOTOLINK

  • ■ CVE-2026-134882: OS command injection in A7100RU router's OpenVPN export (CVSS 10.0) — Firmware 7.4cu.2313_B20191024: the Username value sent to the exportOvpn function in /cgi-bin/cstecgi.cgi is passed to the shell, so a remote attacker can run commands. No CISA rating yet, no known exploitation, not in KEV. The firmware dates from 2019 and TOTOLINK's cstecgi.cgi bugs are regularly picked up by Mirai-style botnets: keep remote management off, and replace the router if no update comes. Source VulDB.
