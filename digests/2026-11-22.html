Curse Catcher — Critical CVEs

D-Link

  • ■ CVE-2026-133993: stack buffer overflow in DIR-600L router's UPnP event handler (CVSS 10.0) (Curse Catcher, Nov 22) — Firmware 2.17b02: a crafted service value sent to gena.cgi (UPnP event subscriptions) overflows the stack and can be triggered remotely. VulDB says the exploit is public. No CISA rating yet, no known exploitation in the wild, and not in KEV. The DIR-600L is an old consumer router and D-Link routers are frequent botnet targets: turn off UPnP and remote management, and replace the device if D-Link no longer ships firmware for it. Source VulDB Write-up.

SurrealDB

  • ■ CVE-2026-134292: embedded JavaScript bypasses function restrictions (CVSS 9.8) (Curse Catcher, Nov 22) — Versions 1.0.0 up to 4.0.0: logged-in users who are blocked from built-in SurrealQL functions can still call them through the surrealdb.functions bridge in embedded JavaScript. It needs an account, so the risk is mainly multi-tenant setups that rely on capability limits. No CISA rating, no known exploitation, not in KEV. Upgrade to 4.0.0, or disable embedded scripting if you don't use it. Source GitHub advisory VulnCheck.

Nexter Blocks Pro (WordPress plugin)

  • ■ CVE-2026-125294: anyone can register as an administrator using look-alike Unicode characters (CVSS 9.8) (Curse Catcher, Nov 22) — Up to 5.0.10: the registration handler blocks the role field by exact bytes, but a key like "ẇp_çapabilities" slips past and the database treats it as the real role field, so a new account becomes administrator. The required token is shown on any page with the login/register block, so it takes one request on sites that allow registration. No CISA rating, no known exploitation, not in KEV. Bugs this easy in WordPress plugins are usually mass-scanned quickly: update past 5.0.10, or turn off user registration until you can. Source Wordfence.
