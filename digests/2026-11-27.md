### VMware (Broadcom) vCenter / ESX

- **[CVE-2026-123903: authentication bypass in vCenter Directory Service (CVSS 9.8)](https://nvd.nist.gov/vuln/detail/CVE-2026-123903)** — Lets an attacker skip login on vCenter Server 8.0, 9.0 and 9.1 and Cloud Foundation 5.x.   [NVD](https://nvd.nist.gov/vuln/detail/CVE-2026-123903) · [Broadcom advisory](https://support.broadcom.com/web/ecx/support-content-notification/-/external/content/SecurityAdvisories/0/39626)

No known exploitation, not in KEV. Same Broadcom advisory; patch hosts alongside vCenter.  
  [NVD](https://nvd.nist.gov/vuln/detail/CVE-2026-123910) · [Broadcom advisory](https://support.broadcom.com/web/ecx/support-content-notification/-/external/content/SecurityAdvisories/0/39626)

### RealVNC

- **[CVE-2026-137738: unauthenticated remote code execution over UDP connections (CVSS 9.8)](https://nvd.nist.gov/vuln/detail/CVE-2026-137738)** — UDP-based connections can be abused without logging in to run code, as root on some platforms, or crash the software.
