## Curse Catcher — Critical CVEs

### MONAI Label (Project MONAI, medical imaging)

- **[CVE-2026-133968: directory traversal leads to remote code execution, exploited in the wild (CVSS 9.8)](https://nvd.nist.gov/vuln/detail/CVE-2026-133968)** — MONAI Label through 0.8.5: an attacker with no account can write files outside the datastore through the image parameter of PUT /datastore/image and get code execution. The CVE record says it has been exploited in the wild since September 2026. Amazon says suspected China-linked attackers used autonomous AI agents (the open-source Cairn framework) to find the bug and take root on a university server. CISA's rating has not caught up (it still shows no known exploitation) and it is not in KEV. Apply the fix from the GitHub advisory and keep MONAI Label servers off the internet.  
  [GitHub advisory](https://github.com/Project-MONAI/MONAILabel/security/advisories/GHSA-qc22-rmgc-vg94) · [Fix PR](https://github.com/Project-MONAI/MONAILabel/pull/1915) · [The Register](https://www.theregister.com/security/2026/11/20/china-attackers-deployed-ai-agents-that-autonomously-found-and-exploited-a-0-day-to-take-over-a-university-server/5311382) · [The Hacker News](https://thehackernews.com/2026/11/attackers-ai-agents-found-zero-day-in.html) · [BleepingComputer](https://www.bleepingcomputer.com/news/security/hackers-use-autonomous-ai-tool-cairn-to-find-zero-day-take-over-server/)

### U.S. Department of the Interior (Unstable Slope Management Program)

- **[CVE-2026-129175: SQL injection without login gives full database control (CVSS 9.8)](https://nvd.nist.gov/vuln/detail/CVE-2026-129175)** — An unauthenticated attacker could inject SQL into this government web application and get root access to its database. It was fixed around Oct 19, so there is nothing for users to patch. CISA rates it as having a public proof-of-concept, scriptable at scale, with full control; not in KEV.  
  [CISA CSAF](https://raw.githubusercontent.com/cisagov/CSAF/develop/csaf_files/IT/white/2026/va-26-324-01.json)

### D-Link

- **[CVE-2026-133680: OS command injection in DCS-935L camera's Local Recording CGI (CVSS 9.9)](https://nvd.nist.gov/vuln/detail/CVE-2026-133680)** — Firmware 1.10.01: the account/password values sent to setconf.cgi are passed to the shell, so a remote attacker can run commands. VulDB says the exploit is public, and CISA rates it as a public proof-of-concept that isn't scriptable at scale but gives full control; not in KEV. This is an older consumer camera and D-Link devices are frequent botnet targets. Keep it off the internet, and replace it if no firmware fix comes.  
  [VulDB](https://vuldb.com/vuln/441406) · [PoC write-up](https://github.com/roit-wolf/CVE/)

### Danfoss

- **[CVE-2026-127057: default credentials on legacy AK-SC 355 and AK-SM 800 refrigeration controllers (CVSS 9.9)](https://nvd.nist.gov/vuln/detail/CVE-2026-127057)** — All versions ship with default passwords that are printed in the product manual, so anyone who can reach the controller can log in. CISA rates it as scriptable at scale with full control, with no known exploitation; not in KEV. These are supermarket and cold-storage controllers, the same kind of device behind this year's European food-spoilage attacks (see the UK fridge story in TLDR). Change the passwords and take them off the internet.  
  [Danfoss advisory](https://www.danfoss.com/en/service-and-support/coordinated-vulnerability-disclosure/danfoss-security-advisories/dsa-2026-12-02/)

### Flowintel

### WordPress plugins

Default settings are vulnerable on sites that also run BuddyPress and Paid Memberships Pro. No CISA rating yet and no exploitation data; not in KEV. An attacker who knows a user's email, including an admin's, can link their own social account and log in as that user. Only affects sites with the Social Login module and a provider enabled. CISA rates it as scriptable at scale with full control, with no known exploitation; not in KEV. Update to 1.2.2.
