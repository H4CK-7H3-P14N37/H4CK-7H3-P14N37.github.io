## Curse Catcher — Critical CVEs

### D-Link

- **[CVE-2026-129353: D-Link DIR-600L login page stack overflow (CVSS 10.0)](https://nvd.nist.gov/vuln/detail/CVE-2026-129353)** — In firmware 2.17/2.17b02 the authentication CGI overflows a stack buffer on an oversized ID or password, reachable remotely without logging in. A public exploit write-up exists; no known exploitation and not in KEV. This is an old consumer router model; replace it if it is still in use, and never expose its web admin to the internet. NVD returned HTTP 503 for this CVE.  
  [NVD](https://nvd.nist.gov/vuln/detail/CVE-2026-129353) · [Researcher write-up](https://github.com/ruanyi101/router-firmware-security-advisories/blob/main/router-firmware-GitHub-advisories/advisories/D-Link-DIR-600L-authentication-cgi.md) · [VulDB](https://vuldb.com/vuln/437416)
- **[CVE-2026-129354: D-Link DIR-600L HNAP handler stack overflow (CVSS 10.0)](https://nvd.nist.gov/vuln/detail/CVE-2026-129354)** — A second remote stack overflow in the same 2.17b02 firmware, this time in the HNAP management interface (the SOAP service D-Link routers use for setup apps). A public exploit write-up exists; no known exploitation and not in KEV. HNAP bugs in D-Link routers have a long history of being folded into botnets, so the same advice applies: replace or isolate.  
  [NVD](https://nvd.nist.gov/vuln/detail/CVE-2026-129354) · [Researcher write-up](https://github.com/ruanyi101/router-firmware-security-advisories/blob/main/router-firmware-GitHub-advisories/advisories/D-Link-DIR-600L-HNAP-SOAPAction.md) · [VulDB](https://vuldb.com/vuln/437417)
- **[CVE-2026-129444: D-Link DSL-6740C hard-coded FTP credentials (CVSS 10.0)](https://nvd.nist.gov/vuln/detail/CVE-2026-129444)** — Firmware dated 2013-11-26 ships an FTP service configured with built-in credentials that anyone who knows them can use remotely. Public evidence of the default login is posted; no known exploitation and not in KEV. Block FTP (port 21) to the modem from the WAN side, or replace this old DSL modem. NVD returned HTTP 503 for this CVE.
