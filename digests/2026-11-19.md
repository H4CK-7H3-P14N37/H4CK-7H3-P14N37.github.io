### F5 BIG-IP

- **[CVE-2026-116953, CVE-2026-120285, CVE-2026-120292, CVE-2026-120722, CVE-2026-121805, CVE-2026-123637: traffic engine crash, possible code execution without login (CVSS 9.8)](https://nvd.nist.gov/vuln/detail/CVE-2026-116953)** — Each flaw needs a specific virtual-server setup: an iRule using GENERICMESSAGE::route, PSC::ip\_address (with an HTTP profile), MR::message route (with an HTTP profile), DNS::scrape or PEM::subscriber, or an APM per-request policy with the Client Information and Endpoint Security agents. A crafted request crashes the traffic engine (TMM) and may allow code execution. Only data-plane traffic is affected, not the management interface. CISA rates them as scriptable at scale with full control. There is no known exploitation and none are in KEV. BIG-IP is a frequent mass-exploitation target, so check your iRules for these commands and patch.  
  [NVD 120285](https://nvd.nist.gov/vuln/detail/CVE-2026-120285) · [NVD 120292](https://nvd.nist.gov/vuln/detail/CVE-2026-120292) · [NVD 120722](https://nvd.nist.gov/vuln/detail/CVE-2026-120722) · [NVD 121805](https://nvd.nist.gov/vuln/detail/CVE-2026-121805) · [NVD 123637](https://nvd.nist.gov/vuln/detail/CVE-2026-123637) · [F5 K000163941](https://my.f5.com/manage/s/article/K000163941) · [F5 K000163937 (APM)](https://my.f5.com/manage/s/article/K000163937) · [The Hacker News](https://thehackernews.com/2026/11/f5-warns-6-critical-big-ip-flaws-can.html)
