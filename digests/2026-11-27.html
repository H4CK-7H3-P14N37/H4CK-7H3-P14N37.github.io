Curse Catcher — Critical CVEs

VMware (Broadcom) vCenter / ESX

  • ■ CVE-2026-123903: authentication bypass in vCenter Directory Service (CVSS 9.8) — Lets an attacker skip login on vCenter Server 8.0, 9.0 and 9.1 and Cloud Foundation 5.x. No known exploitation, not in KEV, no CISA rating yet. vCenter is a long-time favorite of ransomware crews: fix to 9.1.2, 9.0.2.0300 or 8.0 U3m and keep the management interface off the internet. Source NVD Broadcom advisory.
  • ■ CVE-2026-123910: heap out-of-bounds write in ESX I/O filter service (CVSS 9.8) — Memory-corruption bug in ESX 8.0, 9.0 and 9.1 that can lead to code execution on the hypervisor. No known exploitation, not in KEV. Same Broadcom advisory; patch hosts alongside vCenter. Source NVD Broadcom advisory.
  • ■ CVE-2026-123911: use-after-free in ESX I/O filter service (CVSS 9.8) — Second memory-safety flaw in the same ESX service and versions. No known exploitation, not in KEV. Fixed in the same ESXi builds. Source NVD Broadcom advisory.

Mitel OpenScape 4000

  • ■ CVE-2026-137724: unauthenticated access to OpenScape 4000 and Manager (CVSS 10.0) — Broken authentication lets an attacker with no account get into the phone system and read sensitive data. Affects V11 R0.22 through R2.11 and V10 R1.68 and earlier. No known exploitation, not in KEV. Mitel MiCollab bugs were added to KEV just last week, so treat this vendor's PBX gear as a live target. Source NVD Mitel MISA-2026-0013.
  • ■ CVE-2026-137721: command injection in OpenScape 4000 Platform (CVSS 10.0) — Poor input checking lets an attacker run system commands on the PBX. Same versions and advisory. No known exploitation, not in KEV. Source NVD Mitel MISA-2026-0013.
  • ■ CVE-2026-137723: second command injection in OpenScape 4000 Platform (CVSS 9.6) — Another command-injection path in the same component. No known exploitation, not in KEV. Chained with the auth bypass above, this is a full takeover; restrict management access until patched. Source NVD Mitel MISA-2026-0013.

RealVNC

  • ■ CVE-2026-137738: unauthenticated remote code execution over UDP connections (CVSS 9.8) — UDP-based connections can be abused without logging in to run code, as root on some platforms, or crash the software. Hits RealVNC Server before 7.19.1 plus Viewer, Connect, mobile apps and On-Demand Assist. No known exploitation, not in KEV. Remote-access tools are prime initial-access targets: update and block VNC from the internet. Source NVD RealVNC advisory.

Budibase

  • ■ CVE-2026-137498: unauthenticated database wipe/read via prototype pollution (CVSS 10.0) — One request to a public query can erase the MongoDB filter and read, change or delete every record in the collection (3.39.18 to before 4.0.0). No known exploitation, not in KEV. Upgrade to 4.0.0. Source NVD GitHub advisory.
  • ■ CVE-2026-137499: account takeover through unverified-email SSO linking (CVSS 9.8) — An attacker can claim a password-less Builder account by asserting the victim's email at a trusted identity provider, gaining control of all apps and data sources (3.41.0 to before 4.0.0). No known exploitation, not in KEV. Source NVD GitHub advisory.
  • ■ CVE-2026-137494: cross-tenant file read/delete via attachment keys (CVSS 9.9) — A logged-in user with table write access can read or delete other tenants' files in the shared bucket. No known exploitation, not in KEV. Fixed in 4.0.0. Source NVD GitHub advisory.

ToolJet

  • ■ CVE-2026-137536: admin account takeover through SSO email linking (CVSS 9.8) — Google and Git SSO logins are matched only on the provider-supplied email, so an unauthenticated attacker can get a victim's session, admins included. No known exploitation, not in KEV. Upgrade to 3.21.94-beta or later. Source NVD GitHub advisory.

Frappe Framework

No known exploitation, not in KEV. Upgrade to 15.122.0 or 16.50.0. Source NVD GitHub advisory.

llama.cpp (ggml RPC server)

  • ■ CVE-2026-137567: unauthenticated heap write in the RPC server (CVSS 9.8) — Builds b11450 to before b12658 let anyone who can reach the RPC server write to arbitrary heap memory, crashing it or running code. No known exploitation, not in KEV. Update to b12658 and never expose the RPC port beyond trusted hosts. Source NVD Fix release b12658 VulnCheck.

No known exploitation, not in KEV. Source NVD Red Hat.

Direk Tech Smart Portal
