Curse Catcher — Critical CVEs

MONAI Label (Project MONAI, medical imaging)

  • ■ CVE-2026-133968: directory traversal leads to remote code execution, exploited in the wild (CVSS 9.8) — MONAI Label through 0.8.5: an attacker with no account can write files outside the datastore through the image parameter of PUT /datastore/image and get code execution. The CVE record says it has been exploited in the wild since September 2026. Amazon says suspected China-linked attackers used autonomous AI agents (the open-source Cairn framework) to find the bug and take root on a university server. CISA's rating has not caught up (it still shows no known exploitation) and it is not in KEV. Apply the fix from the GitHub advisory and keep MONAI Label servers off the internet. Source GitHub advisory Fix PR The Register The Hacker News BleepingComputer.

U.S. Department of the Interior (Unstable Slope Management Program)

  • ■ CVE-2026-129175: SQL injection without login gives full database control (CVSS 9.8) — An unauthenticated attacker could inject SQL into this government web application and get root access to its database. It was fixed around Oct 19, so there is nothing for users to patch. CISA rates it as having a public proof-of-concept, scriptable at scale, with full control; not in KEV. Source CISA CSAF.

D-Link

  • ■ CVE-2026-133680: OS command injection in DCS-935L camera's Local Recording CGI (CVSS 9.9) — Firmware 1.10.01: the account/password values sent to setconf.cgi are passed to the shell, so a remote attacker can run commands. VulDB says the exploit is public, and CISA rates it as a public proof-of-concept that isn't scriptable at scale but gives full control; not in KEV. This is an older consumer camera and D-Link devices are frequent botnet targets. Keep it off the internet, and replace it if no firmware fix comes. Source VulDB PoC write-up.

Danfoss

  • ■ CVE-2026-127057: default credentials on legacy AK-SC 355 and AK-SM 800 refrigeration controllers (CVSS 9.9) — All versions ship with default passwords that are printed in the product manual, so anyone who can reach the controller can log in. CISA rates it as scriptable at scale with full control, with no known exploitation; not in KEV. These are supermarket and cold-storage controllers, the same kind of device behind this year's European food-spoilage attacks (see the UK fridge story in TLDR). Change the passwords and take them off the internet. Source Danfoss advisory.

Unnamed vendor in CISA ICS advisory ICSA-26-323-02 (Bluetooth braking control)

The CVE record doesn't name the product; see the CISA advisory. CISA rates it as not scriptable at scale with partial impact, with no known exploitation; not in KEV. Source CISA ICSA-26-323-02.

Not scriptable at scale, partial impact, no known exploitation; not in KEV. Source CISA ICSA-26-323-02.

Flowintel

WordPress plugins

  • ■ CVE-2026-120539: Restrictions for BuddyPress runs attacker code from a single GET request (CVSS 9.8) — Up to 1.5.4, the plugin puts the request URL into a PHP eval(), so an unauthenticated attacker can run code with a crafted URL path. Default settings are vulnerable on sites that also run BuddyPress and Paid Memberships Pro. No CISA rating yet and no exploitation data; not in KEV.   • ■ CVE-2026-80188: BuddyBoss Addons Social Login allows admin account takeover (CVSS 9.8) — Up to 1.2.1, the Apple/Facebook login endpoint trusts unverified identity tokens. CISA rates it as scriptable at scale with full control, with no known exploitation; not in KEV. Update to 1.2.2. Source Wordfence BuddyBoss 1.2.2.
  • ■ CVE-2026-129073: authentication bypass in miniOrange OTP Verification (CVSS 9.8) — Versions through 5.6.1 have an alternate path that skips the one-time-password check.   • ■ CVE-2026-129039: PHP object injection in Tribulant Newsletters (CVSS 9.8) — Versions through 4.18.2 deserialize untrusted data, which can lead to code execution if a usable gadget chain is present on the site.
