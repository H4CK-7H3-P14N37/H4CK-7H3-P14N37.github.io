Curse Catcher — Critical CVEs

DrayTek (Vigor2960 VPN router)

  • ■ CVE-2026-129449: Vigor2960 command injection in config upload (CVSS 9.9) (Curse Catcher, Nov 15) — In firmware up to 1.5.1.6, the configuration-upload handler of the web admin CGI passes an attacker-controlled field into a shell command, giving command execution on the router. The researcher's write-up says a logged-in user is needed. VulDB says the exploit is public; no known exploitation and not in KEV. Upgrade to 1.5.1.7. Vigor2960 admin pages were mass-exploited in 2020 (CVE-2020-8515), so keep the web admin off the internet. Source Write-up VulDB Firmware 1.5.1.7.
  • ■ CVE-2026-129450: Vigor2960 path traversal in web backup (CVSS 9.9) (Curse Catcher, Nov 15) — In firmware 1.5.1.6 the web-backup action accepts a path-traversal option, letting a logged-in attacker reach and overwrite files outside the backup folder. Public exploit write-up; no known exploitation and not in KEV. Fixed in 1.5.1.7. Source Write-up VulDB.
  • ■ CVE-2026-129451: Vigor2960 path traversal in guest export (CVSS 9.9) (Curse Catcher, Nov 15) — In firmware up to 1.5.1.6 the guest-export function takes a filename with path traversal, which the write-up says lets a logged-in attacker write or delete arbitrary files. Public exploit write-up; no known exploitation and not in KEV. Fixed in 1.5.1.7. Source Write-up VulDB.
  • ■ CVE-2026-129453: Vigor2960 heap overflow in file-existence check (CVSS 9.9) (Curse Catcher, Nov 15) — In firmware 1.5.1.6 an oversized upload name overflows a heap buffer in the web admin CGI; the write-up shows a logged-in user can crash the CGI and possibly run code. Public exploit write-up; no known exploitation and not in KEV. Fixed in 1.5.1.7. NVD returned HTTP 503 for this CVE. Source Write-up VulDB.

WordPress plugins

  • ■ CVE-2026-122662: Barn2 Document Library Pro PHP object injection (CVSS 9.8) (Curse Catcher, Nov 15) — Versions before 4.2.2 unserialize untrusted data; with a suitable gadget chain on the site this can lead to code execution or file deletion. No known exploitation and not in KEV; update to 4.2.2. Source Patchstack.
  • ■ CVE-2026-125769: Advanced Form Integration privilege escalation (CVSS 9.8) (Curse Catcher, Nov 15) — Versions through 2.11.3 assign privileges incorrectly, letting an attacker raise their role on the site (the 9.8 score implies no login is needed). No known exploitation and not in KEV; update past 2.11.3 or disable the plugin. Role-escalation bugs like this are often mass-scanned soon after disclosure. NVD returned HTTP 503 for this CVE. Source Patchstack.
  • ■ CVE-2026-125795: Estatik real-estate plugin local file inclusion (CVSS 9.8) (Curse Catcher, Nov 15) — Versions through 4.3.6 include a PHP file chosen by the attacker, which can expose config files such as wp-config.php or run code if the attacker can place a file on the server. No known exploitation and not in KEV; update past 4.3.6. NVD returned HTTP 503 for this CVE. Source Patchstack.
