Curse Catcher — Critical CVEs

Fortinet (FortiMail, FortiAnalyzer/FortiManager, FortiOS)

  • ■ CVE-2026-126147: FortiMail path traversal (CVSS 9.8) (Published Nov 11) — Unauthenticated attackers can run code with crafted requests on FortiMail 7.2 (all versions), 7.4.0-7.4.8, 7.6.0-7.6.6 and 8.0.0-8.0.1. No known exploitation yet, but Fortinet edge devices have a long history of mass exploitation soon after disclosure, so patch fast and keep the admin interface off the internet. Source FortiGuard FG-IR-26-199.
  • ■ CVE-2026-126148: FortiMail OS command injection over HA (CVSS 9.8) (Published Nov 11) — Unauthenticated code execution through crafted HA join-request packets on FortiMail 7.6.0-7.6.6 and 8.0.0-8.0.1. Make sure HA ports are reachable only from the cluster peers. Source FortiGuard FG-IR-26-200.
  • ■ CVE-2026-126263: FortiMail SQL injection (CVSS 9.8) (Published Nov 11) — Lets an authenticated attacker run code or commands on FortiMail 7.4.0-7.4.6, 7.6.0-7.6.4 and 8.0.0-8.0.1. Needs a login, so it is lower priority than the two unauthenticated FortiMail bugs. Source FortiGuard FG-IR-26-277.
  • ■ CVE-2026-126170: FortiAnalyzer / FortiManager unauthenticated code execution over HTTP (CVSS 9.8) (Published Nov 11) — A crafted HTTP request can run code on FortiAnalyzer and FortiManager 7.6.0-7.6.7 and 8.0.0-8.0.2, including the Cloud editions and FortiAnalyzer-BigData 7.6.0-7.6.2. FortiManager was mass-exploited in 2024 (FortiJump), so restrict the web interface to management networks. Source FortiGuard FG-IR-26-219.
  • ■ CVE-2026-126262: FortiAnalyzer / FortiManager SQL injection over OFTP (CVSS 9.8) (Published Nov 11) — Unauthenticated attackers who can reach the OFTP port (TCP 514, used by managed devices) can run code on 7.2.x, 7.4.x, 7.6.x and 8.0.x builds. Allow that port only from your own FortiGates. Source FortiGuard FG-IR-26-276.
  • ■ CVE-2026-126259: FortiOS missing authentication in HA sync (CVSS 9.8) (Published Nov 11) — Unauthenticated attackers can run commands as super admin with crafted HA packets on FortiOS 7.2.0-7.2.13, 7.4.0-7.4.12, 7.6.0-7.6.7 and 8.0.0. Only setups that use FGSP with standalone-config-sync, or autoscale, are affected. Source FortiGuard FG-IR-26-273.
  • ■ CVE-2026-126254: FortiOS BGP numeric truncation (CVSS 9.6) (Published Nov 11) — A configured iBGP neighbor can send malformed attributes that spread to every connected router (FortiOS 7.2.0-7.2.13, 7.4.0-7.4.12, 7.6.0-7.6.7, 8.0.0-8.0.1). The attacker has to be, or control, a trusted BGP peer. Source FortiGuard FG-IR-26-268.

Red Hat Quay (container registry)

  • ■ CVE-2026-123710: unauthenticated signing-key takeover (CVSS 9.8) (Published Nov 11) — An anonymous client can install its own signing key through the key-rotation endpoint and then mint tokens that read and write any repository, including private images and tags. That puts the software supply chain at risk: attackers could swap images that get deployed downstream. No known exploitation. Source Red Hat.
  • ■ CVE-2026-110697: cross-tenant robot token theft via SQL wildcard (CVSS 9.9) (Published Nov 11) — A namespace name containing an underscore can match other tenants' robot accounts and return their decrypted tokens. This mainly matters on shared, multi-tenant Quay registries. No known exploitation. Source Red Hat.

Synology DiskStation Manager

  • ■ CVE-2026-76954: DSM Auth API SQL injection (CVSS 9.8) (Published Nov 12) — Remote attackers can read or write arbitrary files and crash the NAS. Fixed in DSM 7.2.1-69057-13, 7.2.2-72806-10, 7.3.2-86009-5 and 7.4.1-90080-1. Ransomware crews regularly target NAS boxes exposed to the internet, so update now and don't expose DSM directly. Source Synology SA-26:19.

Zoho ManageEngine

ManageEngine products have been mass-exploited before, and this one holds Microsoft 365 admin rights. No known exploitation. Source ManageEngine advisory.

WordPress plugins

  • ■ CVE-2026-124815: Clockinator Lite unauthenticated SQL injection (CVSS 10.0) (Published Nov 12) — Before 1.1.0, anyone can delete data from any table and pull password hashes. No known exploitation yet, but it can be scripted at scale and gives full control. Source WPScan.

Self-hosted open-source tools
