## Curse Catcher — Critical CVEs

### RBH Access Technologies (Integra32 access control)

- **[CVE-2026-63079: Integra32 remote code execution as SYSTEM without login (CVSS 9.8)](https://nvd.nist.gov/vuln/detail/CVE-2026-63079)** — Integra32 Security Management System 5.1.11 R5.0 runs an old .NET Remoting service on TCP port 2001 that accepts malicious data from anyone and runs it as SYSTEM, which also allows file read/write and credential theft. This is a building access-control server, so block port 2001 from untrusted networks now. No known exploitation and not in KEV. A researcher's write-up is linked. NVD returned HTTP 503 for this CVE.  
  [NVD](https://nvd.nist.gov/vuln/detail/CVE-2026-63079) · [VulnCheck advisory](https://www.vulncheck.com/advisories/rbh-integra32-net-remoting-deserialization-rce) · [Researcher write-up](https://gist.github.com/VAMorales/b981c0062a9a7e8942439f97246669b6)

### VITEC (EZ TV Platform)

- **[CVE-2026-82504: EZ TV Platform Server unauthenticated web shell upload (CVSS 9.8)](https://nvd.nist.gov/vuln/detail/CVE-2026-82504)** — Before 8.5.0, anyone can upload an ASPX file through the upload handler by naming it in a request header, and the file runs right away on the web server. Patches exist for 8.3.0 through 8.4.1; older releases need 8.5.0 or later. No known exploitation and not in KEV. NVD returned HTTP 503 for this CVE.

### sysPass (password manager)

- **[CVE-2026-129110: sysPass can be reinstalled by anyone, leading to code execution (CVSS 9.8)](https://nvd.nist.gov/vuln/detail/CVE-2026-129110)** — In 3.0.1 through 3.2.11, the installer never checks whether sysPass is already installed. An attacker can re-run it, point the app at their own database, create an admin account and then run commands. This is a self-hosted password vault, so a takeover exposes every stored credential. Keep it off the internet or block the install path until a fix ships. No known exploitation and not in KEV. NVD returned HTTP 503 for this CVE.  
  [NVD](https://nvd.nist.gov/vuln/detail/CVE-2026-129110) · [VulnCheck advisory](https://www.vulncheck.com/advisories/syspass-3.0.1-through-3.2.11-unauthenticated-reinstallation-rce-via-install-install) · [GitHub issue](https://github.com/nuxsmin/sysPass/issues/1954)

### PLANET Technology (managed switches)

- **[CVE-2026-109445: GS-5220-8P2T2S switch stack overflow via login cookie (CVSS 9.8)](https://nvd.nist.gov/vuln/detail/CVE-2026-109445)** — On hardware version 3.0 with firmware before 3.2412b261008, an oversized login cookie in an unauthenticated web request overflows a stack buffer and can crash the switch or corrupt memory. Update the firmware and keep the management web interface off untrusted networks. No known exploitation and not in KEV; NVD has not analyzed it yet.  
  [NVD](https://nvd.nist.gov/vuln/detail/CVE-2026-109445) · [PLANET advisory](https://www.planet.com.tw/en/support/security-advisory/12) · [VulnCheck advisory](https://www.vulncheck.com/advisories/planet-gs-5220-8p2t2s-stack-buffer-overflow-via-webstax-auth-cookie)

### NginxPulse (open-source Nginx log analytics)

That gives them the database contents and, with PostgreSQL superuser rights, the ability to read and write server files. Upgrade to 1.6.26. No known exploitation and not in KEV. NVD returned HTTP 503 for this CVE.
