### DrayTek (Vigor2960 VPN router)

- **[CVE-2026-129449: Vigor2960 command injection in config upload (CVSS 9.9)](https://nvd.nist.gov/vuln/detail/CVE-2026-129449)** _(Curse Catcher, Nov 15)_ — In firmware up to 1.5.1.6, the configuration-upload handler of the web admin CGI passes an attacker-controlled field into a shell command, giving command execution on the router.
