Curse Catcher — Critical CVEs

Dassault Systèmes 3DEXPERIENCE (Station Launcher App)

  • ■ CVE-2026-93664: unauthenticated remote code execution via deserialization (CVSS 10.0) (Curse Catcher, Nov 17) — Affects 3DEXPERIENCE R2023x through R2026x. Untrusted data is deserialized, letting an attacker run code without logging in. CISA rates it as scriptable at scale with full control of the system, but there is no known exploitation and it is not in KEV. Apply the vendor fix and keep the platform off the internet. Source 3DS advisory.
  • ■ CVE-2026-19732 and CVE-2026-77033: OS command injection (CVSS 9.9) (Curse Catcher, Nov 17) — Two separate command-injection bugs in the same component (R2023x through R2026x) let an attacker run commands on the server. The 9.9 score suggests a low-privilege account is needed. CISA rates them as not easily scriptable but with full control if exploited. There is no known exploitation and neither is in KEV. Source NVD CVE-2026-77033 3DS advisory 19732 3DS advisory 77033.

Arize Phoenix (AI observability platform)

  • ■ CVE-2026-53998: template injection exposes secrets and enables admin token forgery (CVSS 10.0) (Curse Catcher, Nov 17) — Versions 13.0.0 to before 15.7.0 let a crafted chat template in a GraphQL query walk Python internals and read environment variables. The endpoint needs no login on default installs. Leaking the Phoenix secret lets an attacker forge admin sessions and decrypt stored credentials. CISA has not rated it yet, there is no known exploitation, and it is not in KEV. Upgrade to 15.7.0 and rotate the secret and any stored provider keys. Source GitHub advisory Fix release 15.7.0.

Zyxel (DSL/Ethernet CPE)

  • ■ CVE-2026-79614: DX3301-T0 / EX3301-T0 out-of-bounds write (CVSS 9.8) (Curse Catcher, Nov 17) — Firmware through 5.50(ABVY.8.3)C0 has a memory-corruption bug in a web library that lets an attacker run commands with a crafted HTTP request and no login. WAN access is off by default, so the main risk is from the LAN or units where remote management was turned on. CISA has not rated it yet, there is no known exploitation, and it is not in KEV. Zyxel home and ISP routers are frequent botnet targets, so patch and keep remote management off. Source Zyxel advisory.

CIRCUTOR PowerStudio SCADA

  • ■ CVE-2026-120387: JWT 'none' algorithm authentication bypass (CVSS 10.0) (Curse Catcher, Nov 17) — The desktop version of PowerStudio SCADA accepts unsigned login tokens, so an attacker can impersonate any user without a password. A researcher write-up is linked from the CVE. CISA has not rated it yet, there is no known exploitation, and it is not in KEV. This is energy-monitoring software for industrial sites, so keep it off the internet and limit it to the OT network. Source Researcher write-up CIRCUTOR security page.

NodePress (Node.js CMS)

  • ■ CVE-2026-129952: admin access by forging tokens with the built-in fallback secret (CVSS 9.8) (Curse Catcher, Nov 17) — Through 8.5.1, if no signing secret is configured, the app falls back to a hardcoded one, so anyone can sign admin tokens. NVD has deferred analysis and CISA has not rated it. There is no known exploitation and it is not in KEV. Set a unique secret. Source VulnCheck advisory.
  • ■ CVE-2026-129955: default admin password 'root' (CVSS 9.8) (Curse Catcher, Nov 17) — Through 8.5.1, if the admin password setting is left unset, the admin login accepts 'root' and gives full control of the site. NVD has deferred analysis and CISA has not rated it. There is no known exploitation and it is not in KEV. Set a strong admin password. Source VulnCheck advisory.

Tensei (Node.js CMS)

  • ■ CVE-2026-129552: hardcoded JWT key lets anyone impersonate admins (CVSS 9.8) (Curse Catcher, Nov 17) — Through 0.11.5, @tensei/auth falls back to a hardcoded signing key when no secret is set, so unauthenticated attackers can sign tokens for any user. CISA rates it as scriptable at scale with full control, but there is no known exploitation and it is not in KEV. Set a secret; the project appears unmaintained. Source VulnCheck advisory.

Prime CMS

  • ■ CVE-2026-129941: anyone can register and get full admin rights (CVSS 9.8) (Curse Catcher, Nov 17) — Through 0.4.0-beta.0, the login check is commented out and every role is hardcoded to admin, so unauthenticated users can create accounts through GraphQL and take over content, users and webhooks. TridotsTech go1cms

The fix is in commit ead8da3 on the version-3 branch. CISA has not rated it yet, there is no known exploitation, and it is not in KEV. Source VulnCheck advisory Fix commit.
