Curse Catcher — Critical CVEs

D-Link

  • ■ CVE-2026-129353: D-Link DIR-600L login page stack overflow (CVSS 10.0) — In firmware 2.17/2.17b02 the authentication CGI overflows a stack buffer on an oversized ID or password, reachable remotely without logging in. A public exploit write-up exists; no known exploitation and not in KEV. This is an old consumer router model; replace it if it is still in use, and never expose its web admin to the internet. NVD returned HTTP 503 for this CVE. Source NVD Researcher write-up VulDB.
  • ■ CVE-2026-129354: D-Link DIR-600L HNAP handler stack overflow (CVSS 10.0) — A second remote stack overflow in the same 2.17b02 firmware, this time in the HNAP management interface (the SOAP service D-Link routers use for setup apps). A public exploit write-up exists; no known exploitation and not in KEV. HNAP bugs in D-Link routers have a long history of being folded into botnets, so the same advice applies: replace or isolate. Source NVD Researcher write-up VulDB.
  • ■ CVE-2026-129444: D-Link DSL-6740C hard-coded FTP credentials (CVSS 10.0) — Firmware dated 2013-11-26 ships an FTP service configured with built-in credentials that anyone who knows them can use remotely. Public evidence of the default login is posted; no known exploitation and not in KEV. Block FTP (port 21) to the modem from the WAN side, or replace this old DSL modem. NVD returned HTTP 503 for this CVE. Source NVD Researcher evidence VulDB.

TRENDnet

  • ■ CVE-2026-129351: TRENDnet TEW-657BRM web server out-of-bounds write (CVSS 10.0) — In firmware 1.00.1 the setup page of the built-in web server writes past a buffer and can be triggered remotely. A public exploit write-up exists; no known exploitation and not in KEV. TRENDnet says the router has been end-of-life for over 15 years and will not be fixed, so the only remedy is to replace it. NVD returned HTTP 503 for this CVE. Source NVD Researcher write-up VulDB.

Edimax

  • ■ CVE-2026-129250: Edimax BR6478ACV2 buffer overflow in PPTP setup (CVSS 9.9) — In firmware 1.23 the PPTP VPN setup form overflows a buffer on an oversized username, reachable remotely. A public exploit write-up exists and Edimax did not respond to the reporter, so no fix is known; no known exploitation and not in KEV. Keep the router's admin page off the internet and limit who can reach it on the LAN. Source NVD Researcher write-up VulDB.

WordPress plugins

  • ■ CVE-2026-120522: Cloud Storage Manager for Fluent Forms file write leading to code execution (CVSS 9.8) — Versions up to 1.2.0 let unauthenticated attackers save their own Google Drive credentials, then download a file whose name contains path traversal, writing attacker content outside the downloads folder. A PHP file dropped in a web-accessible spot means full site takeover. No known exploitation and not in KEV; update the plugin (a fix is in the plugin repository) or remove it. Source NVD Wordfence Fix changeset.
  • ■ CVE-2026-19907: Shipo plugin authentication bypass to admin (CVSS 9.8) — Versions 1.6 through 1.8.0 accept a forged login cookie without checking its signature, so anyone who knows a username (often easy to find) can act as that user, including an admin, and create new admin accounts through the REST API. No known exploitation and not in KEV, but bugs this simple in WordPress plugins tend to be mass-scanned quickly; update now. NVD returned HTTP 503 for this CVE. Source NVD Wordfence Fix changeset.

Dokploy

  • ■ CVE-2026-129433: Dokploy command injection to host takeover (CVSS 9.9) — Before 0.31.1, any authenticated organization member can store a service name with shell characters in a backup job; when the scheduled backup runs it executes as root, and the mounted Docker socket gives control of the whole host. Requires an account, but in multi-user setups that is a low bar. No known exploitation and not in KEV; upgrade to 0.31.1. NVD returned HTTP 503 for this CVE. Source NVD GitHub advisory VulnCheck Release 0.31.1.
