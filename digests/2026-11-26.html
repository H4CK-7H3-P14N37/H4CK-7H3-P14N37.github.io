Curse Catcher — Critical CVEs

HPE Aruba Networking (AirWave)

  • ■ CVE-2026-133973: unauthenticated command injection in AirWave web management (CVSS 9.8) (HPE, Nov 25) — An unauthenticated remote attacker can run operating-system commands on the AirWave server. No known exploitation yet and not in KEV; no CISA rating yet. AirWave manages fleets of wireless gear, so keep its web interface off the internet and patch per HPE bulletin HPESBNW05186. Source NVD HPE advisory.
  • ■ CVE-2026-133971: authentication bypass gives admin access to AirWave (CVSS 9.8) (HPE, Nov 25) — An unauthenticated remote attacker can get administrative access to the AirWave web interface. No known exploitation, not in KEV. Combined with the command injection above, this is a full-takeover path; same HPE fix. Source NVD HPE CSAF.
  • ■ CVE-2026-133972: second authentication bypass in AirWave (CVSS 9.8) (HPE, Nov 25) — An attacker with network access can bypass authentication and perform unauthorized actions. No known exploitation, not in KEV. Fixed by the same HPE bulletin. Source NVD.

Jenkins (Script Security Plugin)

  • ■ CVE-2026-136835: sandbox escape in Jenkins Script Security Plugin (CVSS 9.9) (Jenkins, Nov 25) — Users who can define and run sandboxed scripts, including Pipelines, can run code outside the sandbox via a crafted @Builder annotation. CISA's rating: no known exploitation, not scriptable at scale, but full control if exploited. Not in KEV. Update the plugin past 1436.v1082791135e4 and review who can edit Pipelines. Source NVD Jenkins advisory.

D-Link (R32 router)

  • ■ CVE-2026-136823: OS command injection via the firmware-upload endpoint (CVSS 10.0) (VulDB, Nov 25) — Remote command injection in the R32 web server (firmware 1.10B02) through the fpath parameter. VulDB says exploit details are public; not in KEV, no CISA rating. Consumer routers like this are common botnet targets: disable remote management. Source NVD Write-up.
  • ■ CVE-2026-136821: OS command injection in time settings (CVSS 9.9) (VulDB, Nov 25) — Remote command injection through the time-zone field of SetTimeSettings. Exploit details reported public; not in KEV. Source NVD Write-up.
  • ■ CVE-2026-136822: OS command injection in device settings (CVSS 9.9) (VulDB, Nov 25) — Same time-zone field bug, reached through SetDeviceSettings. Exploit details reported public; not in KEV. Source NVD Write-up.

TOTOLINK (N350RT router)

  • ■ CVE-2026-137043: authorization bypass in N350RT language setting (CVSS 10.0) (VulDB, Nov 26) — Remote authorization bypass through the lang parameter of cstecgi.cgi in recent 2025 firmware. Exploit details reported public; not in KEV. TOTOLINK routers are frequent botnet targets: keep management off the WAN. Source NVD PoC gist.

openIMIS

  • ■ CVE-2026-82489: unauthenticated root RCE in openIMIS report module (CVSS 9.8) (VulnCheck, Nov 25) — The report preview endpoint evaluates attacker-supplied expressions, giving command execution as root plus arbitrary file reads (database credentials, JWT keys). No known exploitation, not in KEV. openIMIS runs national health-insurance systems in several countries; upgrade to release 2026-10. Source NVD VulnCheck advisory.

CISA's rating: public proof-of-concept, scriptable at scale, full control. Not in KEV. Upgrade to 111.44.3. Source NVD GitHub advisory.

ChronoEngine (ChronoForms for Joomla)

  • ■ CVE-2026-133336: unauthenticated file upload in ChronoForms 8 (CVSS 9.5) (Joomla, Nov 26) — Anyone can upload files with dangerous extensions when a file field uses the Filename Provider option, a common route to a web shell. No known exploitation, not in KEV. Update to 8.0.54. Source NVD Vendor.

Open-source libraries (CodeSafe, build-git-clone)

  • ■ CVE-2026-133467: CodeSafe safe_eval() bypass runs arbitrary Python (CVSS 9.8) (GitHub, Nov 25) — Indirect calls slip past the AST check in versions 0.0.1-0.0.4, so attacker-controlled expressions run with the app's permissions. No known exploitation, not in KEV. Upgrade to 0.0.5. Source NVD GitHub advisory.
  • ■ CVE-2026-137090: command injection in build-git-clone via repository URL (CVSS 9.8) (VulnCheck, Nov 25) — Shell characters in the URL passed to clone() run as commands under the Node.js process. No known exploitation, not in KEV. Upgrade to 1.0.4. Source NVD VulnCheck advisory.
