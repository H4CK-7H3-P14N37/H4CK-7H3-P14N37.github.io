Curse Catcher — Critical CVEs

TRENDnet routers

  • ■ CVE-2026-138004: command injection in UPnP control endpoint on TEW-751DR and TEW-733GR (CVSS 10.0) — A remote attacker can inject operating-system commands through the soap.cgi UPnP endpoint on firmware 1.03B01. VulDB says exploit details are public (linked write-up), but there's no known exploitation and it's not in KEV. These are older home and small-office routers: turn off UPnP, never expose it to the WAN, and replace the device if TRENDnet doesn't ship a fix. Source VulDB Public write-up.
  • ■ CVE-2026-138005: command injection in UPnP event handler on TEW-751DR (CVSS 10.0) — A second remote command-injection bug, this time in the UPnP event-notification code (gena.php) of firmware 1.03B01. Exploit details are public per VulDB; no known exploitation and not in KEV. Same advice: disable UPnP or retire the router. Source VulDB Public write-up.

ToolJet

  • ■ CVE-2026-137964: command injection in ToolJet's GitHub Actions release workflow (CVSS 9.8) — The release workflow pastes a pull request's title straight into a shell step, so a crafted PR title, once merged, runs commands with a token that can merge into enterprise repositories. A software supply-chain risk for ToolJet itself rather than for deployed servers. Fixed in 3.21.96-LTS. No known exploitation, not in KEV. A good reminder to audit your own workflows for untrusted PR text in run steps. Source GitHub advisory VulnCheck.

WordPress plugins

  • ■ CVE-2026-134963: WPMasterToolKit code injection (CVSS 9.9) — Lets an attacker inject and run code through the plugin in versions up to 2.26.1. CISA's rating: no known exploitation, not easily automated, but full control of the site if it works. Not in KEV. Source Patchstack.
  • ■ CVE-2026-135933: WebinarIgnition privilege escalation (CVSS 9.8) — Incorrect role assignment lets an attacker raise their privileges, potentially to admin, in versions up to 4.28.1. No known exploitation, not in KEV, no CISA rating yet. Source Patchstack.
  • ■ CVE-2026-134994: Revertix backup/migration plugin PHP object injection (CVSS 9.8) — Unsafe deserialization in versions up to 1.0.3. No known exploitation, not in KEV, no CISA rating yet. Backup plugins hold full site copies, so remove it if unused. Source Patchstack.
  • ■ CVE-2026-136115: MemberPress Discord Addon privilege escalation (CVSS 9.8) — Incorrect role assignment allows privilege escalation in versions up to 1.1.5. No known exploitation, not in KEV, no CISA rating yet. Source Patchstack.
